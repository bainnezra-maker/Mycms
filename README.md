# Church Management System — Complete Testing Build

Upload this repository to GitHub and deploy with Vercel.

## Required Vercel environment variables
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

## Operational test areas
Platform owner, church setup and staff invitations, people/profile hub, families, first timers, follow-up, attendance, giving/finance, events, service planning, rooms/resources, ministries, groups, volunteers, communication records, media, testimonies, prayer, restricted pastoral care, missions, forms, reports and settings.

External SMS/email delivery, payment/MoMo settlement and live-stream transport require provider credentials and are intentionally not faked in this test build.

Never put a Supabase service-role key in the frontend.
